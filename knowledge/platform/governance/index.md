# How decisions are made, recorded, and changed

Portable reasoning context for working inside this repository's governance. It
answers *whose instruction wins?*, *may I change this?*, and *what do I do when
my task asks for something a contract forbids?*

This is **context, not authority** — including about itself. It describes the
governance system; it is not a source of governance.
