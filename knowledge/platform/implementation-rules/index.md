# Rules for writing code here

Portable reasoning context for a coding agent changing this repository. It
answers *what language, and where?*, *which way may dependencies point?*, and
*when is a contract mine to write?*

This is **context, not authority**. It grants nothing, and it never carries the
data a rule is enforced against.

| Concept | Read |
|---|---|
| language boundaries and dependency direction | [boundaries.md](boundaries.md) |
| authored contracts versus generated artifacts | [contracts.md](contracts.md) |

API-specific detail is `platform/api-contract-conventions`; worker-specific
detail is `platform/worker-conventions`; review process is
`platform/review-conventions`.
