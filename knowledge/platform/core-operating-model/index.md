# How this platform behaves

Portable reasoning context for any run on this platform, in the terms the run
itself must reason in. It answers *am I deciding or proposing?*, *what must pass
before anything happens?*, *what do I believe when sources disagree?*, and *what
does an unclear outcome mean?*

This is **context, not authority**. It grants nothing, states no enforced rule or
threshold, and describes no current platform state.
