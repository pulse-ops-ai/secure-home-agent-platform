# How to prove a change is sound

Portable procedure for validating a change to this repository, and for reading
what came back. It answers *what do I run?*, *what did a green result actually
prove?*, and *it is not green — now what?*

This is **context, not authority**. It quotes no expected counts and no
remembered output: the only trustworthy result is the one from the run you just
did.

| what each check establishes, and what it does not | [meanings.md](meanings.md) |
