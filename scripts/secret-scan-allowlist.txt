# Allowlist for scripts/scan-secrets.sh
#
# One entry per line. An entry is a plain substring matched against the scanner's
# "path:lineno:content" result line, so it can be as narrow as you need:
#
#   docs/example.md:42:                  a specific line
#   docs/example.md:                     a whole file (avoid — too broad)
#   EXAMPLE_TOKEN_DO_NOT_USE             a specific literal anywhere
#
# Rules:
#
# 1. Prefer fixing the finding over allowlisting it. An obviously-fake
#    placeholder ("replace-me") does not trip the scanner; a realistic-looking
#    one does, and that is the scanner working correctly.
# 2. Keep entries narrow. A whole-file entry recreates the blind spot this
#    allowlist exists to avoid.
# 3. Every entry needs a comment explaining why it is not a secret.
# 4. Never allowlist a path under .github/workflows/. Workflows are the highest
#    consequence place for a credential to leak, and they define execution
#    permissions.
#
# Currently empty: there are no false positives, because there are no
# credential-shaped values in this repository at all.
