# Governance registry

This directory owns repository governance data under
[ADR-0021](../docs/decisions/ADR-0021-establish-machine-readable-governance-state.md).
The root agent contract applies; this domain has no separate agent contract.
Normative decision records remain separate from this domain; this registry does not rewrite their bodies.

`state.json` is the canonical version-one registry. Its schema and shared model
live in `scripts/governance/`; `consumers.json` records governed consumer ownership
and migration boundaries. `genesis-source-manifest.json` preserves the immutable
source evidence for genesis. Changes must satisfy the current and history gates.

From the repository root, use `node scripts/query-governance-state.mjs --json`
for machine-readable answers. `STATE.md` and the registered regions in the
decision index and question rationale are generated projections, not authored
copies. Use the renderer's explicit write operation and then its separate check;
never edit generated bytes by hand. Pre-attestation preparation has its own
explicit base, bundle and freshness bindings.

Registry data grants no implementation permission, runtime authority, capability,
deployment authorization or household access. External task authority and runtime
controls retain their own boundaries.
