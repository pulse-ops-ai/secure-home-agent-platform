# packages/query-model

Projection configuration and the validated query AST.

> **Status: package boundary only.** No projection-config type, no AST — that is **issue #28**.

## What belongs here

- The **projection configuration** type: fields, includes, filters and their
  permitted operators, sorts, defaults, cursor tie-breaker, pagination and
  include limits.
- The **validated query AST** that models and MCP clients produce, and the
  validator that rejects anything a module did not declare
  ([ADR-0012 §12](../../docs/decisions/ADR-0012-adopt-typescript-nestjs-pnpm-implementation-stack.md)).

## What does not belong here

- **Per-module configurations.** Each API module owns its own; this package owns
  the *shape*.
- **SQL, ORM predicates, or query building.** The AST is validated here and
  compiled by a repository — never generated by a model.
- **Authorization.** Authorization may narrow a projection for a caller and may
  never widen it, but that decision is not made here.
