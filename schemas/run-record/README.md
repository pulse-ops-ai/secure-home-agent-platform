# schemas/run-record/

Generated JSON Schema for the **run-record** contract: the run identity, launching profile identity, and the closed terminal vocabulary (only COMPLETED maps to success).

> **Generated output — never hand-edited.** The authored source is the Zod
> contract in [`packages/events`](../../packages/events/), regenerated via
> `pnpm --filter @secure-home/events run generate`. Each file's `$id` embeds
> the exact contract version and is recorded in
> [`../identity-ledger.json`](../identity-ledger.json) (authored, historically
> append-only). Drift and identity are enforced by the contract packages'
> conformance suites (`runner-domain-contracts`, L2/#51).
