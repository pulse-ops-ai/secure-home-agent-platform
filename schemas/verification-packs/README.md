# schemas/verification-packs/

Generated JSON Schema for the **verification-packs** contract: named groupings of gate identities — a pack references gates by id and cannot declare an executable.

> **Generated output — never hand-edited.** The authored source is the Zod
> contract in [`packages/contracts`](../../packages/contracts/), regenerated via
> `pnpm --filter @secure-home/contracts run generate`. Each file's `$id` embeds
> the exact contract version and is recorded in
> [`../identity-ledger.json`](../identity-ledger.json) (authored, historically
> append-only). Drift and identity are enforced by the contract packages'
> conformance suites (`runner-domain-contracts`, L2/#51).
